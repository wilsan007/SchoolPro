# Directives MCP Builder

Permet d'ajouter ou d'éditer des connecteurs de serveurs MCP personnalisés pour étendre les outils de l'agent.

## 1. Directives de configuration
* Configurer les serveurs dans le fichier `mcp_config.json`.
* Valider le bon fonctionnement des commandes d'initialisation et s'assurer que le chemin absolu vers le binaire est correct.
