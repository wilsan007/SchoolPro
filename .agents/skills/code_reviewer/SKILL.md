# Directives Code Reviewer

Ce skill fournit les règles d'inspection et de correction automatique du code source.

## 1. Critères de Revue
* **Clarté :** Pas de logique alambiquée ou imbriquée inutilement.
* **Séparation des responsabilités :** Un composant ou une fonction doit avoir une seule responsabilité.
* **Respect des types :** Pas de type `any` en TypeScript sans justification majeure.
