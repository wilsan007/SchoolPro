# Directives Composio Expert

Ce skill détaille l'utilisation de Composio pour connecter des applications tierces (Slack, GitHub, Calendar, etc.).

## 1. Intégration
* Utiliser les clés d'API et variables d'environnement de manière sécurisée.
* Structurer les triggers et les actions de manière asynchrone pour ne pas bloquer les requêtes principales.
