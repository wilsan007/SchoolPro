# Directives Awesome Claude Skills

Ce skill compile les meilleures techniques pour optimiser les performances des modèles Claude.

## 1. Gestion de Contexte
* **XML Tags :** Structurer les entrées complexes avec des balises XML (ex: `<instructions>`, `<code_context>`).
* **Concision :** Éviter le superflu et privilégier des réponses directes et denses en contenu technique.

## 2. Patterns de Code
* Adopter des architectures fonctionnelles, claires et modulaires.
