## Détails par catégorie

### 1. Qualité du code

#### ESLint ✅

#### TypeScript ✅

- **Résultat :** 0 erreur
- Toutes les règles non négociables du `AGENTS.md` sont respectées (pas de `@ts-ignore` injustifié)

#### type-coverage ✅
- **Commande :** `pnpm exec type-coverage --strict --at-least 80 --detail`
- **Résultat :** **98.22%** (391 730 / 398 812 types stricts)
- Seuil : ≥80% → ✅
- Les ~1.78% restants sont principalement dans `.next/types/` (générés par Next.js)

#### Knip ⚠️
- **Commande :** `pnpm exec knip --no-progress`
- **Résultat :** Exit 0 mais ~15 exports inutilisés détectés
- **Exports inutilisés notables :**
  - Types générés Supabase : `Json`, `TablesUpdate`, `Enums`, `CompositeTypes`
  - Interfaces : `EdgeRateLimitResult`, `RlsQueryResult`, `SourceTache`, `PersonneEnRetard`
  - Types RLS : `RlsParams`, `ElevesWithRlsArgs`, `EleveByIdWithRlsArgs`, etc.
- **Duplicate export :** `prisma|default` dans `src/lib/prisma.ts`
- **23 config hints :** patterns `knip.json` à nettoyer (entrées redondantes, binaires à ignorer)
- **Recommandation :** Nettoyer `knip.json` et supprimer les exports vraiment inutilisés

### 2. Sécurité

#### Semgrep ⚠️
- **Commande :** `semgrep --config .semgrep.yml .`
- **Résultat :** Exit 0, findings `explicit-any`
- **Fichiers concernés :**
  - `src/lib/export.ts` — `format?: (value: any, row: T) => string`
  - `src/lib/notifications/telegram.ts` — `.filter((u: any) => ...)`, `.map((u: any) => ...)`
  - `src/lib/prisma-site-scoped.ts` — `type PrismaModel = Record<string, (...args: any[]) => Promise<any>>`
- **Recommandation :** Typer ces callbacks avec des génériques ou `unknown` où possible

#### Gitleaks ⚠️
- **Commande :** `gitleaks detect --source . --config .gitleaks.toml --no-banner --verbose`
- **Résultat :** 28 leaks trouvés, tous dans `.env.example`
- **Nature :** Clés placeholder Stripe (`mpk_test_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`)
- **Statut :** Faux positifs — ce sont des exemples, pas des secrets réels
- **Recommandation :** Ajouter `.env.example` aux exclusions `.gitleaks.toml` ou marquer comme `allowlist`

#### Trivy FS ⚠️
- **Commande :** `trivy fs --severity HIGH,CRITICAL --no-progress .`
- **Résultat :** Vulnérabilités transitives dans `node-tar`
- **CVEs :**
  - CVE-2026-23745, CVE-2026-23950, CVE-2026-24842, CVE-2026-26960
  - CVE-2026-29786, CVE-2026-31802, CVE-2026-59874, CVE-2026-73566
- **Mitigation :** Le `overrides` dans `package.json` force déjà `tar ^7.5.16`. Les CVEs restantes sont dans des versions transitives non résolvables sans mise à jour Next.js.
- **Recommandation :** Surveiller les mises à jour Next.js qui bumpent `node-tar`

### 3. SQL & Base de données

#### Squawk ⊘
- **Commande :** `pnpm exec squawk prisma/migrations/`
- **Résultat :** "Failed to find files for provided patterns"
- **Cause :** Squawk attend des fichiers `.sql` individuels, pas un dossier avec sous-dossiers
- **Recommandation :** Utiliser `squawk prisma/migrations/**/*.sql` ou ajuster le script

#### SQLFluff ⚠️
- **Commande :** `sqlfluff lint --config .sqlfluff prisma/migrations/ supabase/`
- **Résultat :** Issues de formatage (indentation, espacement)
- **Règles :** LT01 (spacing), LT02 (indent)
- **Recommandation :** Lancer `sqlfluff fix` pour auto-formater les migrations

### 4. Dépendances & Architecture

#### Madge ✅
- **Commande :** `pnpm exec madge --circular --extensions ts,tsx src/`
- **Résultat :** **0 circular dependency** — 1008 fichiers analysés en 2.6s

#### dependency-cruiser ⚠️
- **Commande :** `pnpm exec dependency-cruiser src --config .dependency-cruiser.cjs`
- **Résultat :** 45 violations (43 errors, 2 warnings)
- **Cycles détectés :**
  1. `auth.ts → tenant-claims.ts → prisma.ts → demo-horizon.ts → demo-now.ts → auth.ts`
  2. `auth.ts → prisma.ts → demo-horizon.ts → demo-now.ts → auth.ts`
  3. `audit.ts → prisma.ts → demo-horizon.ts → demo-now.ts → auth.ts → audit.ts`
- **Nature :** Cycle connu lié à la résolution Prisma + démo-horizon/auth
- **Recommandation :** Casser le cycle en lazy-loadant `demo-now`/`demo-horizon` dans `auth.ts` ou extraire les fonctions de démo dans un module séparé

#### pnpm audit ✅
- **Commande :** `pnpm audit --prod`
- **Résultat :** **No known vulnerabilities found** — 0 vulnérabilité production
